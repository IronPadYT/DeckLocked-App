For this app to work you have to do several things. 
Firstly download the app to your desktop in an unzipped folder. It needs the other files/images in the same folder.

You will need to download and install Node JS for it to work as I don't know enough about coding to make it an executable. (If somebody wants to make it an executable feel free and message me if you want me to share it).
https://nodejs.org/en/download

Once this is installed open your CMD prompt (windows key + type cmd).

Type "cd Desktop" and press enter. (Without the quotation marks)
Type "cd wow-challenge-app" (This is the folder name, if you changed the name of the folder you will have to type it exactly here)
Type "npm start" and this should run the app.

------------------------------------------GUIDE FOR USING THE APP:--------------------------------------------

Firstly click the person icon at the top. Type your profile name in and hit save.
This will retype your name into the text box as there is a bug which doesnt allow you to type in there once you have saved/loaded/deleted a profile.

When you create a new character make sure to increase Level to 2 by clicking the cog and the + once. As when you draw cards it uses your level on the top for the requirements so this will allow you to match what you can unlock in game. Otherwise for example if you ding level 6 in game, it will still say level 5 in the app which means you cannot draw any of the new level 6 abilities.

The cog wheel has some manual adjustment buttons in case things go wrong and you need to fix the values.

When you draw cards make sure to click them once they are drawn to ensure they are unlocked.


-----------------------------------------------------KNOWN BUGS ------------------------------------------------
